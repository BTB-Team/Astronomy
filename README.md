# انجمن ستاره‌شناسی افغانستان

یک پروژه React + Vite برای وب‌سایت انجمن ستاره‌شناسی افغانستان.

## ساختار پروژه

```text
src/
  assets/
    images/      تصاویر سایت
    videos/      ویدئوهای سایت
  components/
    home/        بخش‌های صفحه اصلی
  data/          داده‌های قابل استفاده در کامپوننت‌ها
  App.jsx        چیدمان اصلی صفحات
  main.jsx       نقطه شروع برنامه
  index.css      استایل‌های عمومی
```

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

## بررسی کیفیت کد

```bash
npm run lint
```
